# Menu artwork

The site uses these supplied images directly from this folder:

| File | Used for |
|---|---|
| `fondo.jpg` | title screen background (cover, any size) |
| `btn-play.png`, `btn-settings.png`, `btn-credits.png` | the three title buttons |
| `barra.png` | loading bar frame shown **only after Play** (with progress filling its center) |
| `dsu.png` | icon beside **DSU Remote** in the Settings tab and the DSU settings heading |

These assets are included with the deployed web client so the background and
buttons render on GitHub Pages. Missing images fall back to plain Wii-style
buttons, but are not expected to be missing in the published build.
